# ASM Project - Mini Libc++

A personal project to learn x86-64 assembly (NASM).

The best way to learn a language is to build something real with it, so the goal here is to recode the C standard library (libc) in assembly, then go further by adding extra functions and algorithms that the libc doesn't provide.

## Requirements

- Linux x86-64
- [NASM](https://www.nasm.us/)
- `ld` (GNU binutils)
